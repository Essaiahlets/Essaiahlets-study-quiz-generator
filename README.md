# 🧠 AI-Powered Study Quiz Generator

An AI-powered study quiz generator using Tether's QVAC SDK to generate quizzes on-device.

## ✨ Features

* AI-powered quiz generation
* Uses Tether's QVAC SDK
* Runs AI processing on-device
* Simple study quiz generation

## 🛠️ Technologies

* JavaScript
* Node.js
* Tether QVAC SDK

## 🚀 Installation

```bash
npm install
```

## ▶️ Usage

```bash
node app.js
```

## 🤖 QVAC SDK

This project uses the QVAC SDK to load and run an AI model locally for quiz generation.
